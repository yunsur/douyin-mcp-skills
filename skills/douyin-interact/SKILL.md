## 输入判断

根据用户意图路由：

- 点赞 / 取消点赞 → 点赞流程
- 收藏 / 取消收藏 → 收藏流程
- 发表评论 → 评论流程
- 回复评论 → 回复流程

参数 `aweme_id`（作品 id 或链接）来自搜索、推荐流或详情结果；无法确定时先查/先搜。

## 约束

- **评论和回复执行前必须展示内容让用户确认**（以用户身份公开发表，无法撤回）
- 点赞、收藏可直接执行（可逆，且服务端幂等：已点赞再点赞自动跳过，反之同理）
- 不要对同一作品短时间重复调用；不要批量刷赞/刷评

## 执行流程

### 点赞 / 取消点赞

调用 `digg_video`：

- `aweme_id`（string，必填）— 作品 `aweme_id` 或作品链接
- `digg_type`（string，可选）— `1` 点赞（默认） | `0` 取消点赞

### 收藏 / 取消收藏

调用 `collect_video`：

- `aweme_id`（string，必填）— 作品 `aweme_id` 或作品链接
- `action`（string，可选）— `1` 收藏（默认） | `0` 取消收藏

### 发表评论

调用 `post_video_comment`：

- `aweme_id`（string，必填）
- `content`（string，必填）— 评论内容
- `reply_id`（string，可选）— 留空为一级评论

**发送前**：把最终评论文本原样展示给用户，得到确认后再调用。

### 回复评论

同样使用 `post_video_comment`：

- `aweme_id`（string，必填）
- `content`（string，必填）— 回复内容
- `reply_id`（string，必填）— 目标评论 ID（来自 `get_video_comments` / `get_all_video_comments` 返回的 `comment_id`）

**发送前**展示「回复 @某人：内容」让用户确认。

## 失败处理

| 场景 | 处理 |
|---|---|
| 未登录 | 引导使用 douyin-login |
| 缺少 `aweme_id` | 先搜索或浏览作品拿到 id，不要编造 |
| 评论被限制（需关注/级别不足/已关闭） | 如实告知平台限制，不尝试绕过 |
| 评论发送失败或内容违规 | 展示错误，建议修改措辞后重试 |
| 人机验证 / 403 | 停止连续调用，等待后重试 |
