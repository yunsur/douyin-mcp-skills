## 执行流程

### 1. 明确策划需求

先向用户确认：

- 赛道/领域（如：电动车、母婴、美食）
- 目标：选题灵感 / 对标分析 / 趋势判断 / 起号策略
- 是否已有对标账号

### 2. 采集与分析

**热点与趋势**

- `get_hot_search_board` — 当前热搜，判断大盘热度
- `search_videos`（`sort_type=2` 最新发布）— 近期新内容方向
- `search_videos`（`sort_type=1` 最多点赞）— 该赛道的爆款结构

**爆款拆解**（对高互动作品）

- `get_video_detail`（`video` = `aweme_id`）— 文案、封面、时长、互动比
- `get_all_video_comments`（`video`，`limit` 控制量，`include_replies` 视需要）— 评论区关注点、用户原话、需求与抱怨

**对标账号**

- `search_users`（`keyword`）找到候选账号
- `get_user_info`（`user`）— 粉丝量、获赞量、内容定位
- `get_user_all_posts`（`user`，`limit` 建议先取 20–50）— 内容矩阵、发布频率、爆款占比

**话题与关键词**

- `search_suggest`（`keyword`）— 用户真实搜索写法
- `search_challenges`（`keyword`）— 相关话题的热度与参与度

### 3. 输出策划建议

整理为可执行结论：

- **选题方向**：3–5 个，按预估热度与竞争度排序
- **标题/开头模板**：从爆款文案中提炼（痛点式、悬念式、对比式…）
- **话题标签**：主标签 + 长尾标签组合
- **内容结构建议**：时长、节奏、评论区引导
- **发布节奏**：参考对标账号的频率与时段
- **风险提示**：赛道是否已过度饱和、是否有合规风险

## 约束

- 这是**只读分析 skill**，不执行点赞、评论、私信、发布等任何写操作（用户明确要求时，转到对应 skill 并按其确认流程执行）
- 采集量控制：单次 `limit` ≤ 50，多关键词分次搜索并留间隔
- 结论必须标注数据来源（哪次搜索 / 哪个账号 / 多少样本），不做无依据的断言
- 只做用户指定赛道的分析，不扩展到无关账号的隐私数据

## 失败处理

| 场景 | 处理 |
|---|---|
| 未登录 | 引导使用 douyin-login |
| 搜索无结果 | 换关键词/近义说法，或用 `search_suggest` 确认用户真实写法 |
| 数据量不足以支撑结论 | 如实说明样本量，给出初步观察并建议扩大采集 |
| 频繁请求被限流 | 降低频率、等待后重试，抓取分批完成 |
| 对标账号数据不可见 | 换其它对标账号，或改用其作品列表推断 |
