## 输入判断

根据素材判断发布类型：

- 提供了视频文件 → 视频作品（`publish_with_video`）
- 提供了图片 → 图文作品（`publish_content`）
- 仅提供文本 → 提示用户至少提供图片或视频（抖音不支持纯文本作品）

## 约束

- **发布前必须展示完整内容让用户确认**（发布后无法撤回，代表用户的公开作品）
- **视频必须是本地绝对路径**（服务需要读本地文件），不支持网络链接
- 图文与视频不能混用，只能二选一
- 图文作品至少 1 张图片
- 标签通过 `tags` 参数单独传，不要写在正文里（服务会处理格式）
- 标题/正文长度遵循创作者中心限制（标题约 30 字、正文约 1000 字），超长会被截断
- 发布依赖创作者环境变量：`DOUYIN_TICKET`、`DOUYIN_TS_SIGN`、`DOUYIN_CLIENT_CERT`、`DOUYIN_PRIVATE_KEY`，**另需 `DOUYIN_DTRAIT_BLOB`**；缺失时工具会返回明确错误，需先按 `/setup-douyin-mcp` 配置

## 执行流程

### 1. 收集发布信息

确保齐全：

- `content`（必填，图文/视频都要）— 正文/文案
- `title`（可选）— 标题
- 图片列表（图文必填）或视频路径（视频必填）
- `tags`（可选）— 话题标签列表
- `visibility`（可选）— 可见范围

信息不完整时向用户询问缺少的部分。

### 2. 内容校验

- 视频路径是否为绝对路径（`/Users/...`、`/home/...`），否则让用户改成绝对路径
- 图片是否为可读的本地文件或图片 URL
- 标题/正文字数是否超限
- 若用户给的是网页内容：先用 WebFetch 提取文本与图片，再进入步骤 3

### 3. 确认发布

向用户展示预览：标题、正文、标签、图片列表或视频路径、可见范围。**等待用户明确确认**后才执行。

### 4. 发布

**图文** — 调用 `publish_content`：

- `content`（string，必填）
- `title`（string，可选）
- `images`（string[]，图文必填）— 本地图片路径或图片 URL 列表
- `tags`（string[]，可选）
- `visibility`（string，可选）

**视频** — 调用 `publish_with_video`：

- `content`（string，必填）
- `video`（string，必填）— 本地视频**绝对路径**
- `title`（string，可选）
- `tags`（string[]，可选）
- `visibility`（string，可选）

### 5. 报告结果

成功后告知用户作品 id / 状态；失败则原样展示工具返回的错误。

## 失败处理

| 场景 | 处理 |
|---|---|
| 未登录 | 引导使用 douyin-login |
| 缺少创作者凭据（ticket / dtrait） | 按 `/setup-douyin-mcp` 配置环境变量后重启服务 |
| 视频用了相对路径 | 提示改为绝对路径 |
| 图片路径无效 / 不存在 | 提示检查路径，或改用图片 URL |
| 标题或正文超长 | 提示用户缩短 |
| 账号无发布权限 | 说明该账号可能未开通创作者权限 |
| 发布失败（风控 / 需验证） | 展示错误，建议稍后重试或降低发布频率 |
